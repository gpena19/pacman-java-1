🟡 About the Project
This Pac-Man project is a Java-based arcade game recreation using JPanel and Swing. It includes a tile-based map with functioning wall collision, food pellets, power-ups, and ghost enemies. Ghosts change behavior and appearance when Pac-Man eats a power pellet, including a blinking animation before power-up ends.

The game features:

✅ Fully animated Pac-Man and ghosts

👻 Four ghost types with random movement logic

⚡ Power-up mode with scared/blinking ghosts

🍒 Fruit (cherry) that spawns for bonus points

🔁 Side warping from left to right

🎵 Looping background music using music.wav

🧠 Object-oriented structure with game loop and collision detection

It was built from scratch in Java, and designed to mimic the fun, chaos, and charm of the original game — with a few modern touches!
